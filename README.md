# 🌸 Web Skincare

Sebuah website informasi seputar skincare yang membantu pengguna memahami jenis kulit dan memilih produk yang sesuai.

## ✨ Fitur Utama

- Halaman Beranda
- Informasi jenis kulit
- Panduan memilih produk skincare
- Skinpedia: ensiklopedia singkat bahan aktif dalam skincare
- Halaman produk skincare

## 🧪 Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

## 📂 Struktur Folder

├── index.html # Halaman utama
├── produk.html # Daftar produk skincare
├── skinpedia.html # Informasi bahan skincare
├── skintype.html # Info jenis kulit
└── assets/ # Gambar, ikon, dan file statis lainnya
